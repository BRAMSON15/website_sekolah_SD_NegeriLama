  ForeignKeys: registration_id → ppdb_registrations, user_id → users

  - Stats component: wire:poll-5000ms (5 second interval)
  - Activity feed: wire:poll-3000ms (3 second interval)
  - Search: wire:model.debounce-500ms="search"

Performance:

  - Activities cached 120 seconds
  - Indexed DB queries
  - Debounced search input

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Polling not updating
  → Check browser console for errors
  → Verify Livewire installed: php artisan livewire:install
  → Check Laravel logs: tail storage/logs/laravel.log

Issue: No activities showing
  → Verify migrations ran: php artisan migrate:status
  → Check table: mysql> SELECT * FROM ppdb_activities;
  → Check registrations exist: SELECT * FROM ppdb_registrations;

Issue: Stats incorrect
  → Clear cache: php artisan cache:clear
  → Check query manually: SELECT COUNT(*) FROM ppdb_registrations WHERE status='pending'
  → Check migration ran successfully

Issue: Search not working
  → Verify indexes created (check migration)
  → Check query in tinker: php artisan tinker
  → Try manual search query

================================================================================
CONFIGURATION OPTIONS
================================================================================

To speed up polling (more frequent updates):
  Change in blade views: wire:poll-3000ms → wire:poll-2000ms

To reduce polling frequency (save resources):
  Change in blade views: wire:poll-5000ms → wire:poll-10000ms

To change search debounce:
  Change in blade views: debounce-500ms → debounce-300ms (faster) or 1000ms (slower)

To change cache duration:
  Edit PpdbMonitoringService.php:
    STATS_CACHE_TIME = 180 (seconds)
    ACTIVITIES_CACHE_TIME = 120 (seconds)
